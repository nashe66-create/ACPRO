## Completion rule
A gate is not complete because a document exists. It is complete when required deliverables are sufficiently defined, reviewed and accepted.

## Change control
Material changes to an accepted decision must:
1. Be proposed explicitly.
2. State what is changing.
3. Explain why.
4. Identify affected documents.
5. Update the Decision Log.
6. Update the relevant roadmap/backlog items.
