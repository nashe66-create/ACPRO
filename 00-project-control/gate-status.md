## Change control

Material changes to an accepted decision must:

1. Be proposed explicitly.
2. State what is changing.
3. Explain why.
4. Identify affected documents.
5. Update the Decision Log.
6. Update the relevant roadmap/backlog items.

## Current operating rule

Ideas are captured in the backlog and classified NOW / NEXT / LATER / REJECTED. They do not derail the current deliverable unless a formal decision changes the roadmap.
